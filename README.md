## About

Endless Dropper is an endless dropper game where you survive for as long as possible while avoiding obstacles.

**How long can you survive?**

The game gets progressively more challenging as you continue, testing your movement, reaction time, and ability usage.

## How to Play

### Keyboard

- **WASD** - Move
- **Hold Space / Left Mouse Button** - Use Ability

### Controller

- **Left Stick** - Move
- **Right Stick** - Navigate menus
- **Hold X** - Use Ability

(Controller has not been fully tested, so issues may present themselves)

## Gameplay

- Avoid obstacles and survive as long as possible.
- As you survive, you get more coins which can be used to buy abilities.
- Use abilities strategically to extend your run.
- The longer you survive, the harder the game becomes.

## Endless Theme

This game is built around the idea of an endless challenge.

There is no final level or finish line, since every run is about trying to beat your previous score, and seeing how long you can survive.

## Features

- Endless gameplay
- Increasing difficulty
- Unlockable abilities (Only 2 since I ran out of time)
- Score and high score tracking
- Colorful obstacle-based gameplay
- Accessibility options (No headache mode and mute)

## Accessibility

⚠️ WARNING: This game contains bright colors and some visual effects. If you are sensitive to flashing lights, play with caution.

A **No Headache Mode** option is available to reduce some visual intensity.
